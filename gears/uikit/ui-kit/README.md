# @gears-web/ui-kit

Standard React component base for Constructor Fabric front-end templates.
Behavior from Base UI, styling via CSS Modules on semantic CSS-variable tokens,
variants via CVA.

```ts
import '@gears-web/ui-kit/theme.css';
import '@gears-web/ui-kit/styles.css';

import { Button } from '@gears-web/ui-kit';
```

Currently private and unpublished (development phase). See the
[gear documentation](https://github.com/constructorfabric/gears-web/tree/main/gears/uikit)
for the design, quickstart, and component docs.
